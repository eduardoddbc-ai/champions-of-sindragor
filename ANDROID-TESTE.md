# Teste Android — Champions of Sindragor v182

1. PC e Android devem estar na mesma rede.
2. Inicie API e WEB do jogo no PC permitindo acesso pela rede local.
3. Instale o APK de debug gerado pelo GitHub Actions.
4. Abra Champions of Sindragor.
5. Informe o endereço do WEB no PC, por exemplo `http://192.168.0.166:5173`.
6. Toque em ENTRAR NO JOGO.

A API continua rodando no PC durante esta fase de desenvolvimento; o APK é o cliente Android para testar interface, touch, animações, inventário e combates no aparelho real.
